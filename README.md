# 🎓 英语伴学 · LingoMate

**零依赖 · 纯前端 · 本地运行** 的小学英语伴学网页：闯关练习 + 单词跟读 + 课文跟读 + 单词听写，手机扫码即玩。

A **zero-dependency, pure-frontend, locally served** companion app for primary-school English.

⚠️ 本项目仅供个人 / 家庭学习参考，**不提供任何担保**，且不含教材内容的任何授权。使用前请先阅读 [免责声明](#disclaimer)。

</div>

> 🌐 **在线体验**：项目已部署到 GitHub Pages，无需本地起服务，直接打开 <https://lingomate.github.io/> 即可使用（手机、电脑浏览器均可）。

## 这是什么

给孩子做日常英语伴学的本地网页应用。课本（沪教版 / 上海教育出版社）以 **JSON 题库** 的形式描述，程序本身不含任何具体题目——代码、关卡、题库三层分离，加一本新课本只需加一个 JSON 文件。

全部功能跑在浏览器里：语音朗读用系统内置的 **Web Speech API**（不联网、不上传），进度与听写记录存在 `localStorage`。电脑起一个本地 HTTP 服务，手机连同一个 WiFi 扫码即可使用，也可以把网页"添加到主屏幕"当成小程序用。

## 四种模式

| 模式 | 图标 | 说明 |
|---|---|---|
| 课文跟读 | 🗣️ | 整篇课文字幕滚播，播一句跟读一句；对话按说话人自动分配不同男/女音色；自动模式为**滑动开关 + 停顿滑条**（5/10/15 秒，默认 5 秒）；页顶有**语速滑条**（慢/稍慢/正常/稍快 4 挡，全局记忆） |
| 单词跟读 | 🔤 | 全单元词汇表逐词跟读：**单卡显示**当前播音词（上英文大字、下中文释义），点卡片重听；同样支持自动模式与语速滑条 |
| 闯关练习 | 🎯 | 从本单元题库随机抽 **15 题**作答，答对 **70%** 通关（15 题需 11 题），按得分给 1~3 ⭐；三~五年级题型为单词 / 句型 / 听写 / 语音 / 交际，**一、二年级只考 单词 / 听音辨词 / 读音 三类（无听写）** |
| 单词听写 | ✏️ | 全单元词汇，**顺序随机、每词读三遍**，可选 5/10/15 秒间隔；播放中不显示单词内容，纸笔写完后按播放顺序逐词勾选自检，成绩自动记入听写记录。**仅题型含"听写"的单元显示该卡片**（一、二年级自动隐藏） |

其它能力：

- **多课本**：首页自动列出 `data/books.json` 里的所有课本，按年级、上下册排序；进度按课本分别保存。
- **语速滑条**：所有有朗读的界面（跟读 / 听写 / 闯关）顶部都有 4 挡语速滑条（慢 / 稍慢 / 正常 / 稍快），存 `localStorage` 全局生效；跟读里松手即重读当前句试听。
- **自动朗读**：进入新题自动朗读题干英文，答题后只朗读**正确选项**（完形填空不提前播放，避免广播答案）；可随时切 🔊/🔇。
- **判分细节**：听写忽略大小写与多余空格；多空完形按空序以 `;` 分隔答案并整句补全后朗读。
- **面包屑导航**：首页 › 课本 › 单元 › 当前模式，任意层级一键回退。
- **听写记录**：保留最近 200 次，含逐词掌握数据（`items`），可按单元查看次数 / 平均分 / 最近分。
- **平板适配**：触屏设备（优先 iPad mini）自动放大卡片、字号与触控目标，地图竖屏 3 列 / 横屏 4 列；电脑端外观不变。
- **课本音视频**：单元页「📺 课本音视频」卡片进入**侧栏播放器**（可收起目录 + 播放区 + Whisper 英文字幕逐句高亮 / 点句跳转）；课文跟读小节标题带「▶️ 板块朗读」直达曲目，且配好 cues 映射后**逐句直接播教材原音片段**（未命中自动回退 TTS）。素材来自 `media/`，入口是否显示完全由 `media/manifest.json` 决定，**没有素材的课本 / 单元自动隐藏、回退纯 TTS**。详见「课本音视频」一节。
- **免责声明内置**：首次打开（或条款版本升级后）弹窗确认，底部常驻「📜 免责声明与版权说明」可随时查看；条款统一在 [`DISCLAIMER.md`](DISCLAIMER.md) 维护（改后跑 `python sync_disclaimer.py`），同步到 [本文件末尾](#disclaimer) 与 [`app.js`](app.js) 内嵌弹窗；[`serve_qr.py`](serve_qr.py) 头部注释另有要点提示。
- **反馈与建议**：底部入口用 `mailto` 预填设备 / 浏览器环境信息发给作者，不经过任何服务器、不上传数据。

## 快速开始

### 方式一：一键启动（Windows，推荐）

1. 双击 [`启动手机伴学.bat`](启动手机伴学.bat)
2. 命令行里打印出本机局域网地址，例如 `http://192.168.1.23:8000/`
3. **手机与电脑连同一个 WiFi**，在电脑浏览器打开该地址——页面**右上角会自动显示一个小二维码**（纯前端离线生成），点一下放大后用 iPhone 相机扫码；也可直接在 Safari 里手动输入该地址
4. 关掉命令行窗口即停止服务；窗口关不掉时双击 [`停止服务.bat`](停止服务.bat)

> 二维码由页面内 [`qr.js`](qr.js) **纯前端离线生成**，直接编码"浏览器当前实际访问地址"，不联网、不向任何第三方发送数据；手机端访问时该二维码会自动隐藏。
> 只想在电脑上用：直接访问 `http://localhost:8000/` 即可。

### 方式二：手动起服务

```bash
# 必须用 HTTP 方式打开，直接双击 index.html 会因浏览器安全限制读不到题库
py serve_qr.py              # 或 python serve_qr.py
# 不想用二维码脚本，任意静态服务器都可以
python -m http.server 8000
```

### 方式三：不经过电脑

本应用是纯静态文件，任何"静态托管"都能跑：把 `index.html` / `app.js` / `data/` 保持目录结构部署到任意静态主机（GitHub Pages、公司内部服务器、家里的 NAS 均可），手机直接访问该网址。

> 注意：**不要把 `index.html` 拷到手机后用 Safari 直接打开**——`file://` 下浏览器禁止读取本地 JSON，题库必然加载失败。手机上想用，请用一个带本地 HTTP 服务的文件管理 App，或者部署成网址访问。

## 题库数据格式

`data/books.json` 是一个数组，每项登记一本课本：

```json
[
  { "id": "3A", "file": "data/3A.json" },
  { "id": "4A", "file": "data/4A.json" },
  { "id": "4B", "file": "data/4B.json" }
]
```

`data/<id>.json` 的契约（详见 [`教材转题库-技能提示词.md`](教材转题库-技能提示词.md)）：

```json
{
  "id": "6A",
  "title": "六年级上册",
  "subtitle": "上海教育出版社 · 沪教版",
  "icon": "📙",
  "units": [
    {
      "name": "Unit 1",
      "title": "中文单元名",
      "icon": "🏃",
      "color": "#ff9800",
      "en": "单元英文标题（可选，有则显示并可 🔊 朗读）",
      "vocab": [ { "en": "go jogging", "cn": "去慢跑" } ],
      "read":  [ { "en": "Mum: Hurry up!", "cn": "妈妈：快点！",
                   "st": "课文 · 板块名", "sp": "p.4–5", "sec": "拓展阅读" } ]
    }
  ],
  "questions": {
    "1": [
      { "type": "单词", "q": "\"do chores\" 的中文意思是？",
        "options": ["放风筝", "做家务", "去野餐", "和朋友玩"], "answer": 1 },
      { "type": "句型", "q": "My grandpa ____ lots of plants.",
        "options": ["have", "has", "is", "like"], "answer": 1 },
      { "type": "听写", "q": "仔细听单词，拼写出它的英文", "word": "go jogging", "cn": "去慢跑" },
      { "type": "语音", "q": "Find the word in which the letter a says a different sound.",
        "options": ["cat", "apple", "cake", "bag"], "answer": 2 },
      { "type": "交际", "q": "想说\"…\"，应选哪句？",
        "options": ["…", "…", "…", "…"], "answer": 0 }
    ]
  }
}
```

要点：

- `questions` 的键是**单元号字符串** `"1".."N"`，值是该单元的完整题库（每次闯关从中随机抽 15 题）。
- 题型白名单：**单词 / 句型 / 听写 / 语音 / 交际**（引擎额外认识 `课文`/`拓展` 两种历史标签的配色，新教材不要再用）；**一、二年级只用 单词 / 听音辨词 / 读音 三类**（`听音辨词` 与 `读音` 靠 `word` 字段驱动 🔊 自动朗读，无听写）。
- 选择题**恰好 4 个选项**，`answer` 为 `0..3` 的整数，并在单元内大致均匀分布。
- 完形填空归入"句型"：题干用连续下划线 `____`，多空答案按空序以 `;` 分隔。
- 听写题的 `word` 必须只含字母 / 数字 / 撇号 / 空格（带 `.` `…` 会导致朗读与判分异常），`q` 一律用固定文案 `仔细听单词，拼写出它的英文`。
- `vocab` 决定听写与**单词跟读**内容（单卡：上英文、下中文），`read` 决定课文跟读内容；两者为空的单元，对应模式卡片会自动置灰。
- `read` 的 `st` 字段是分小节标题：中高年级用 `课文 · …` / `拓展阅读 · …`；一、二年级固定三小节 `歌曲 · 课本歌谣` → `故事 · …` → `字母 · …`（上册）/ `拼读 · …`（二年级自然拼读韵脚）。

## 添加一本新课本（三步，不用改代码）

1. 复制 `data/3A.json` 为 `data/5B.json`，改 `id` / `title` / `icon` 和题目内容（格式完全一致）。
2. 在 `data/books.json` 加一行 `{ "id": "5B", "file": "data/5B.json" }`。
3. 刷新页面。引擎会自动按年级、册别排序；课本超过一本时首页自动出现"选择课本"界面。

想从 PDF 电子课本自动生成题库（含图片版教材逐页精读、页码偏移实测、词汇表/跟读句/题目配额、合并校验脚本），把 [`教材转题库-技能提示词.md`](教材转题库-技能提示词.md) 全文交给具备读图能力的 AI 代理，并附一句"教材 PDF 在 `<路径>`，生成 `6A` 的题库文件"。

## 课本音视频（media/）

教材配套板块音频与故事 / 选学视频放在 `media/`，App 通过 `media/manifest.json` 探测并展示入口：

```
media/
├── manifest.json           清单（勿手改，由脚本扫描生成）
└── <课本id>/               如 1A
    ├── audio/unit<N>/      板块音频：Ready go / Story / Letters / Communicate
    │                       / Extend / words / 总 等 .MP3（文件名大小写、空格、
    │                       个别拼写笔误都能识别，规则见 make_media_manifest.py）
    ├── subs/               字幕 WebVTT：与音频同名同相对路径（make_media_subtitles.py 生成）
    ├── cues/               句子→原音时间段映射 unit<N>.json（make_media_cues.py 生成）
    └── video/              板块视频：文件名需含 Unit<N> 与 Story / Extend，如
                            「一上 Unit1 P4 Story.mp4」
```

使用流程：

1. 把音频放进 `media/1A/audio/unit1/`、视频放进 `media/1A/video/`（新建课本 id / unitN 目录即可）。
2. （可选）跑一次 `python make_media_subtitles.py 1A` 用本地 Whisper（faster-whisper，CPU 即可）把音频转写成英文字幕，脚本会自动重生成清单。转写工具只在**开发机**上需要（`pip install faster-whisper`），不影响 App 本身的零依赖运行；国内网络默认走 hf-mirror 下载模型。
3. （可选，推荐）再跑 `python make_media_cues.py 1A`：把 `data/1A.json` 的跟读句与字幕**按文本对齐**，生成「句子 → 原始音频时间段」映射（`media/1A/cues/unitN.json`）。之后**课文跟读播到命中的句子会直接放教材原音对应片段**（真人的语气、连读、拟声词都比 TTS 好），未命中的句子自动回退 TTS；当前句有原音时页头显示「🎧 教材原音」徽标。改了 `data/1A.json` 的句子原文后重跑此脚本即可（映射里带原文校验，改过未重跑的句子自动回退 TTS，不会播错）。
4. 刷新页面：该单元模式页出现「📺 课本音视频」卡片，进入**侧栏播放器**——左侧目录可点 ◀ 收起成图标窄条（状态记忆），列出本单元全部音频 / 视频（带 `CC` 标记者有字幕），右侧播放区；音频播放时下方**字幕面板逐句高亮、随进度滚动、点句可跳转定位**。课文跟读各小节标题带「▶️ 板块朗读」（歌曲→Ready go、故事→Story、字母/拼读→Letters、拓展→Extend），直达播放器对应曲目；右上角「📺 视频」跳到播放器。

设计约定：

- **无素材即无入口**：某课本 / 单元没有文件时，音视频入口隐藏、朗读回退浏览器 TTS。`media/` 现已随仓库提交，**公网部署（GitHub Pages）也会携带这些音视频**——远程访客打开 1A 单元即可加载它们；若不想公开媒体，删除仓库中的 `media/` 或将其加入 `.gitignore` 即可，前端无需改动（探测不到自动降级）。
- **播放互斥**：进播放器 / 切曲目自动 `stopSpeech()` 停 TTS；切页即停。
- **字幕是机器转写**：Whisper 对清晰教学音频准确率很高，但**专有名词、拟声词可能有误**（如 "Miaow" 拼法），仅作听读辅助，以课本原文为准；`--force` 可重转。

## 常见问题

**Q：打开显示"⚠️ 题库加载失败"。**
A：几乎都是直接双击了 `index.html`（`file://` 下浏览器禁止 `fetch` 本地 JSON）。请用 `启动手机伴学.bat` 或 `python -m http.server 8000` 起服务后通过 `http://` 访问。

**Q：手机打不开电脑上的地址。**
A：确认手机与电脑在同一个 WiFi（不是手机流量/访客网络）；Windows 防火墙首次可能弹窗询问，需要允许专用网络访问 8000 端口；仍不行就在电脑上打开 `http://localhost:8000/` 验证服务本身是否正常。

**Q：没有声音 / 朗读很怪。**
A：朗读用的是系统自带语音。① 系统需安装英文语音包（iOS：设置 → 通用 → 辅助功能 → 朗读内容；Windows：设置 → 时间和语言 → 语音）；② 苹果设备请静音键未静音、并允许 Safari 播放声音；③ 首次进入题目可能需要点一下 🔊 唤醒语音。

**Q：听写能不能中途暂停 / 跳过某个词？**
A：可以。播放中随时用 ⬅上一个 / 下一个 ➡ 跳词、🔊 重听这个词，或点 ⏹ 结束播放——自检清单只包含**已播放过**的词，不会剧透未听的词。

**Q：进度能同步到别的设备吗？**
A：不能，进度只存在各设备浏览器本地。想保留记录请在一台设备上稳定使用，或自行导出 `localStorage`。

**Q：8000 端口被占用。**
A：改 `serve_qr.py` 顶部的 `PORT = 8000`（同时把 `停止服务.bat` / `stop_server.ps1` 里的端口号一起改掉），或先双击 `停止服务.bat` 清掉旧进程。

- `stop_server.ps1` 需保留 **UTF-8 BOM**，否则 Windows PowerShell 5.1 会按 ANSI 解码，输出乱码。
