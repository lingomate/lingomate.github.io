# 🎓 英语伴学 · LingoMate

**零依赖 · 纯前端 · 本地运行** 的小学英语伴学网页：闯关练习 + 单词听写 + 课文跟读，手机扫码即玩。

A **zero-dependency, pure-frontend, locally served** companion app for primary-school English.

## 这是什么

给孩子做日常英语伴学的本地网页应用。课本（沪教版 / 上海教育出版社）以 **JSON 题库** 的形式描述，程序本身不含任何具体题目——代码、关卡、题库三层分离，加一本新课本只需加一个 JSON 文件。

全部功能跑在浏览器里：语音朗读用系统内置的 **Web Speech API**（不联网、不上传），进度与听写记录存在 `localStorage`。电脑起一个本地 HTTP 服务，手机连同一个 WiFi 扫码即可使用，也可以把网页"添加到主屏幕"当成小程序用。

## 三大模式

| 模式 | 图标 | 说明 |
|---|---|---|
| 闯关练习 | 🎯 | 从本单元题库随机抽 **15 题**作答，答对 **70%** 通关（15 题需 11 题），按得分给 1~3 ⭐；题型为单词 / 句型 / 听写 / 语音 / 交际 |
| 单词听写 | ✏️ | 全单元词汇，**顺序随机、每词读三遍**，可选 5/10/15 秒间隔；播放中不显示单词内容，纸笔写完后按播放顺序逐词勾选自检，成绩自动记入听写记录 |
| 课文跟读 | 🗣️ | 整篇课文字幕滚播，播一句跟读一句；对话按说话人自动分配不同男/女音色，支持"自动模式"（读完歇 5/10/15 秒自动下一句） |

其它能力：

- **多课本**：首页自动列出 `data/books.json` 里的所有课本，按年级、上下册排序；进度按课本分别保存。
- **自动朗读**：进入新题自动朗读题干英文，答题后只朗读**正确选项**（完形填空不提前播放，避免广播答案）；可随时切 🔊/🔇。
- **判分细节**：听写忽略大小写与多余空格；多空完形按空序以 `;` 分隔答案并整句补全后朗读。
- **面包屑导航**：首页 › 课本 › 单元 › 当前模式，任意层级一键回退。
- **听写记录**：保留最近 200 次，含逐词掌握数据（`items`），可按单元查看次数 / 平均分 / 最近分。
- **免责声明内置**：首次打开（或条款版本升级后）弹窗确认，底部常驻「📜 免责声明与版权说明」可随时查看；条款全文同时写在 [本文件末尾](#disclaimer)、[README-en.md](README-en.md#disclaimer)、[`app.js`](app.js) 与 [`serve_qr.py`](serve_qr.py) 头部注释里。

## 快速开始

### 方式一：一键启动（Windows，推荐）

1. 双击 [`启动手机伴学.bat`](启动手机伴学.bat)
2. 浏览器会弹出二维码图片，同时命令行里打印出本机局域网地址，例如 `http://192.168.1.23:8000/`
3. **手机与电脑连同一个 WiFi**，用 iPhone 相机扫码，或在 Safari 里手动输入该地址
4. 关掉命令行窗口即停止服务；窗口关不掉时双击 [`停止服务.bat`](停止服务.bat)

> 显示二维码图片需要电脑能上网（二维码由在线图片服务生成）；网址本身完全不依赖外网。
> 只想在电脑上用：直接访问 `http://localhost:8000/` 即可。

### 方式二：手动起服务

```bash
# 必须用 HTTP 方式打开，直接双击 index.html 会因浏览器安全限制读不到题库
py serve_qr.py              # 或 python serve_qr.py
# 不想用二维码脚本，任意静态服务器都可以
python -m http.server 8000
```

### 方式三：不经过电脑

本应用是纯静态文件，任何"静态托管"都能跑：把 `index.html` / `app.js` / `data/` 保持目录结构部署到任意静态主机（GitHub Pages、公司内部服务器、家里的 NAS 均可），手机直接访问该网址。

> 注意：**不要把 `index.html` 拷到手机后用 Safari 直接打开**——`file://` 下浏览器禁止读取本地 JSON，题库必然加载失败。手机上想用，请用一个带本地 HTTP 服务的文件管理 App，或者部署成网址访问。

## 题库数据格式

`data/books.json` 是一个数组，每项登记一本课本：

```json
[
  { "id": "3A", "file": "data/3A.json" },
  { "id": "4A", "file": "data/4A.json" },
  { "id": "4B", "file": "data/4B.json" }
]
```

`data/<id>.json` 的契约（详见 [`教材转题库-技能提示词.md`](教材转题库-技能提示词.md)）：

```json
{
  "id": "6A",
  "title": "六年级上册",
  "subtitle": "上海教育出版社 · 沪教版",
  "icon": "📙",
  "units": [
    {
      "name": "Unit 1",
      "title": "中文单元名",
      "icon": "🏃",
      "color": "#ff9800",
      "en": "单元英文标题（可选，有则显示并可 🔊 朗读）",
      "vocab": [ { "en": "go jogging", "cn": "去慢跑" } ],
      "read":  [ { "en": "Mum: Hurry up!", "cn": "妈妈：快点！",
                   "st": "课文 · 板块名", "sp": "p.4–5", "sec": "拓展阅读" } ]
    }
  ],
  "questions": {
    "1": [
      { "type": "单词", "q": "\"do chores\" 的中文意思是？",
        "options": ["放风筝", "做家务", "去野餐", "和朋友玩"], "answer": 1 },
      { "type": "句型", "q": "My grandpa ____ lots of plants.",
        "options": ["have", "has", "is", "like"], "answer": 1 },
      { "type": "听写", "q": "仔细听单词，拼写出它的英文", "word": "go jogging", "cn": "去慢跑" },
      { "type": "语音", "q": "Find the word in which the letter a says a different sound.",
        "options": ["cat", "apple", "cake", "bag"], "answer": 2 },
      { "type": "交际", "q": "想说\"…\"，应选哪句？",
        "options": ["…", "…", "…", "…"], "answer": 0 }
    ]
  }
}
```

要点：

- `questions` 的键是**单元号字符串** `"1".."N"`，值是该单元的完整题库（每次闯关从中随机抽 15 题）。
- 题型白名单：**单词 / 句型 / 听写 / 语音 / 交际**（引擎额外认识 `课文`/`拓展` 两种历史标签的配色，新教材不要再用）。
- 选择题**恰好 4 个选项**，`answer` 为 `0..3` 的整数，并在单元内大致均匀分布。
- 完形填空归入"句型"：题干用连续下划线 `____`，多空答案按空序以 `;` 分隔。
- 听写题的 `word` 必须只含字母 / 数字 / 撇号 / 空格（带 `.` `…` 会导致朗读与判分异常），`q` 一律用固定文案 `仔细听单词，拼写出它的英文`。
- `vocab` 决定听写内容，`read` 决定跟读内容；两者为空的单元，对应模式卡片会自动置灰。

## 添加一本新课本（三步，不用改代码）

1. 复制 `data/3A.json` 为 `data/5B.json`，改 `id` / `title` / `icon` 和题目内容（格式完全一致）。
2. 在 `data/books.json` 加一行 `{ "id": "5B", "file": "data/5B.json" }`。
3. 刷新页面。引擎会自动按年级、册别排序；课本超过一本时首页自动出现"选择课本"界面。

想从 PDF 电子课本自动生成题库（含图片版教材逐页精读、页码偏移实测、词汇表/跟读句/题目配额、合并校验脚本），把 [`教材转题库-技能提示词.md`](教材转题库-技能提示词.md) 全文交给具备读图能力的 AI 代理，并附一句"教材 PDF 在 `<路径>`，生成 `6A` 的题库文件"。

## 技术说明

| 主题 | 实现 |
|---|---|
| 运行时依赖 | 无。纯 HTML + 原生 JS + Python 标准库；不打包、不构建、无 npm 依赖 |
| 语音 | 浏览器内置 `speechSynthesis`，优先 `en-US` 音色；题干只提取英文部分朗读（`___` 读作 "blank"），对话按说话人分配音色 |
| iOS 兼容 | ① 音色列表异步加载 → 轮询直到就绪；② iOS Safari 长朗读约 15 秒自动停 → 8 秒 `pause()/resume()` 续命；③ `viewport-fit=cover` + `safe-area-inset` 适配刘海；④ 禁止双击缩放与电话号码识别 |
| 状态存储 | `localStorage`，键为 `english_quiz_progress_<bookId>`（闯关进度）与 `english_quiz_dict_records_<bookId>`（听写记录）；换设备或清缓存即丢失 |
| 渲染 | 单页骨架 + `innerHTML` 增量重渲染；跟读列表只构建一次骨架，换句仅迁移高亮，避免闪动 |
| 服务端 | `serve_qr.py`：根路径 `/` 映射到 `index.html`（避免中文文件名编码问题）、目录列表只显示 html、静默访问日志 |
| 安全 | 全部数据本地，不发起任何业务网络请求（二维码图片除外）；选本页的课本标题经 `escapeHtml` 转义。题库 JSON 按本地可信内容处理，请勿加载来源不明的题库文件 |

## 常见问题

**Q：打开显示"⚠️ 题库加载失败"。**
A：几乎都是直接双击了 `index.html`（`file://` 下浏览器禁止 `fetch` 本地 JSON）。请用 `启动手机伴学.bat` 或 `python -m http.server 8000` 起服务后通过 `http://` 访问。

**Q：手机打不开电脑上的地址。**
A：确认手机与电脑在同一个 WiFi（不是手机流量/访客网络）；Windows 防火墙首次可能弹窗询问，需要允许专用网络访问 8000 端口；仍不行就在电脑上打开 `http://localhost:8000/` 验证服务本身是否正常。

**Q：没有声音 / 朗读很怪。**
A：朗读用的是系统自带语音。① 系统需安装英文语音包（iOS：设置 → 通用 → 辅助功能 → 朗读内容；Windows：设置 → 时间和语言 → 语音）；② 苹果设备请静音键未静音、并允许 Safari 播放声音；③ 首次进入题目可能需要点一下 🔊 唤醒语音。

**Q：听写能不能中途暂停 / 跳过某个词？**
A：可以。播放中随时用 ⬅上一个 / 下一个 ➡ 跳词、🔊 重听这个词，或点 ⏹ 结束播放——自检清单只包含**已播放过**的词，不会剧透未听的词。

**Q：进度能同步到别的设备吗？**
A：不能，进度只存在各设备浏览器本地。想保留记录请在一台设备上稳定使用，或自行导出 `localStorage`。

**Q：8000 端口被占用。**
A：改 `serve_qr.py` 顶部的 `PORT = 8000`（同时把 `停止服务.bat` / `stop_server.ps1` 里的端口号一起改掉），或先双击 `停止服务.bat` 清掉旧进程。

## 版本管理与换行符

- 本仓库带 [`.gitattributes`](.gitattributes)：`*.bat` / `*.cmd` 强制以 **CRLF** 签出，源码与文档（含 `*.ps1`）强制 LF。
- **不要删除该文件**，否则 clone 到 macOS / Linux（或 `core.autocrlf=false` 的 Windows 机器）会得到 LF 版 `.bat`；cmd.exe 解析 `rem` 行时错位、把注释当命令执行，表现为**双击启动脚本一闪而过、启动不了**。
- `.bat` 里的注释请用纯 ASCII 的 `rem` 行；中文在 `chcp 65001` 生效前按 OEM 代码页解析，容易出问题。
- `stop_server.ps1` 需保留 **UTF-8 BOM**，否则 Windows PowerShell 5.1 会按 ANSI 解码，输出乱码。
- `英语/`（教材 PDF，约 697 MB）已在 [`.gitignore`](.gitignore) 中忽略，不会进入版本库。

### 5. 数据与隐私

- 本应用**没有账号系统、不联网请求任何业务接口、不上传任何数据**。闯关进度与听写记录只以明文形式保存在浏览器的 `localStorage` 里，键名为 `english_quiz_progress_<bookId>` 与 `english_quiz_dict_records_<bookId>`；另有一个 `english_quiz_disclaimer_ack_<version>` 记录你是否确认过本条款（不含任何个人信息）。
- 这意味着：**清理浏览器缓存、换设备、换浏览器或使用无痕模式，进度与记录都会丢失且无法找回**。重要的成绩请自行截图或导出保存。
- ⚠️ **唯一的第三方网络请求**：[`serve_qr.py`](serve_qr.py) 生成二维码时，会把你的**本机局域网 IP 和访问地址**作为参数发送给第三方图片服务 `api.qrserver.com`（该地址形如 `http://192.168.x.x:8000/`，属内网地址，但仍会暴露你的使用行为与网络环境）。若你介意这一点，请不要用"打开二维码"的方式，改为：直接看命令行打印的网址手动在手机上输入，或自行用离线工具生成二维码（把 `serve_qr.py` 里的 `webbrowser.open(qr)` 一行注释掉即可完全断开该请求）。
- 除此之外，页面运行期间不会向外发送任何请求：词汇、题目、课文句子全部来自本地 `data/*.json`，朗读音频由浏览器 / 系统的内置 TTS 现场合成，不下载任何在线音频。

### 6. 使用与安全注意事项

- **局域网暴露**：`serve_qr.py` 监听 `0.0.0.0:8000`，且它是**静态文件服务**——同一局域网内的其他设备不仅能访问页面，**还能按路径下载本目录下的任意文件**（包括 `英语/` 里的教材 PDF、`data/*.json` 题库；只有目录列表做了 html-only 过滤，直接给路径照样能取到）。请勿在机场、咖啡厅等公共或不受信网络下开启；不需要时及时关闭窗口或双击 [`停止服务.bat`](停止服务.bat)。若本机装有第三方同步 / 内网穿透工具，风险同样适用。
- **题库按本地可信内容处理**：引擎只对少数动态字符串做了转义，`data/*.json` 中的文本会被当作 HTML 渲染。请**不要加载来源不明的题库文件**，也不要在其中写入不可信内容。
- **儿童使用需家长陪同**：本应用面向小学阶段学生，请家长控制屏幕使用时间；设备上的系统语音、浏览器权限与网络设置也建议由家长代为管理。
- 本项目**不收集、也无法查看**任何使用者的学习数据；不存在"云端同步""排行榜""老师端"之类的功能。
